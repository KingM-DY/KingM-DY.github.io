# kingm-site 部署到阿里云 ECS 指南

> 目标：把个人主页（React + Vite 静态站点）部署到你刚买的阿里云 ECS，
> 实现**国内直连、免梯子**访问，后续绑自定义域名 + ICP 备案。

---

## 第 1 步：拿到登录信息

1. 阿里云控制台 → **云服务器 ECS** → **实例**
2. 复制右侧 **公网 IP**（形如 `47.x.x.x`）
3. 首次使用需 **重置实例密码**：实例 → 更多 → 密码/密钥 → 重置实例密码，设一个 root 密码

---

## 第 2 步：登录 ECS

**方式 A（最简单，推荐）：浏览器内终端**
- 实例 → **远程连接** → **Workbench / 立即登录**
- 输入 root + 你设的密码，直接进入终端

**方式 B：本机 SSH**
```bash
ssh root@你的公网IP
```

---

## 第 3 步：在 ECS 上装 Nginx（一键）

把 `setup-ecs.sh` 传到 ECS（控制台文件上传，或本机 `scp setup-ecs.sh root@IP:/root/`），然后：
```bash
bash /root/setup-ecs.sh
```
脚本会自动：装 Nginx → 建 `/var/www/kingm-site` → 写配置 → 启动并开机自启。

---

## 第 4 步：把网站文件传上去

在本机（不是 ECS）执行：
```bash
scp -r "D:\AI Tool\WorkBuddy WorkSpace\2026-07-25-17-33-42\kingm-site\dist\*" root@你的公网IP:/var/www/kingm-site/
```
> 如果 scp 报错，也可在阿里云控制台用"文件上传"功能把 dist 内文件拖进去。

传完后在 ECS 确认：
```bash
ls /var/www/kingm-site/   # 应看到 index.html 等
```

---

## 第 5 步：验证

浏览器打开 **http://你的公网IP** （先不用域名、不用 HTTPS 也能看）。
能看到个人主页（含水果商城作品卡）即成功。

> 如果打不开：检查 ECS **安全组**是否放行 80 端口（入方向 0.0.0.0/0 : 80）。
> 控制台 → 实例 → 安全组 → 配置规则 → 快速添加规则 → 选 HTTP(80)。

---

## 第 6 步：备案 + 绑域名（可选但推荐）

1. **买域名**：阿里云域名注册，建议 `kingm.site` / `kingmstudio.cn`（¥50–100/年）
2. **ICP 备案**：阿里云备案系统填表（需本 ECS 实例支撑，已满足资格），约 1–2 周免费通过
3. **解析**：域名控制台 → 解析 → 添加 A 记录，指向 ECS 公网 IP
4. **改 Nginx**：回 ECS 把 `server_name _` 改成你的域名，重启：
   ```bash
   sed -i 's/server_name _;/server_name kingm.site www.kingm.site;/' /etc/nginx/conf.d/kingm-site.conf
   nginx -t && systemctl restart nginx
   ```
5. **免费 HTTPS**（备案后）：
   ```bash
   dnf install -y certbot python3-certbot-nginx
   certbot --nginx -d kingm.site -d www.kingm.site
   ```

## 流量成本提醒

- 主页 dist ≈ 3MB，背景视频 ≈ 16MB（视频现来自海外 CloudFront，后续可迁到 ECS）
- 约 19MB/次完整访问；1000 次 ≈ ¥13
- 建议：阿里云 **费用中心 → 预警设置** 开 ¥10/月 预警，防爬虫/盗链
